# How to run SCEMS (the short version)

This workbook is a **desk for Training**, not a filing cabinet you browse.

## Day to day (four things)

1. **SCEMS → Trainees — start here** — one row per person  
2. **SCEMS → Work my queue** — approve / return skills one at a time  
3. **SCEMS → What needs attention?** — when something feels off  
4. **SCEMS → Backup now** — about once a month  

That is the job. Everything else is machinery.

## If the tab bar looks like chaos

**SCEMS → Make this spreadsheet simple**

Hides Form Responses, ledgers, engines, and old role views. Deletes nothing.
Puts you on TRAINEES.

## Who uses what

| Who | Where |
| --- | --- |
| You (Training) | This spreadsheet — decide and record |
| FTOs / trainees / MD | The **portal** (role screens) |
| Forms | The nine live Google Forms only — never a “Copy of …” |

## When something breaks

1. **What needs attention?** — it names the exact next function  
2. **More → Repair forms & sheets** / **Recover skills & rebuild matrix** if it says so  
3. **More → Show every tab** only while you are repairing; then **Hide the clutter** again  

## What you should not do

- Do not delete Form Responses tabs on the live book (copy first, then clean the copy)  
- Do not submit to a form titled “Copy of …”  
- Do not paste code into the underscore-named twin spreadsheet  
- Do not use bulk-approve tools (retired on purpose)  

## After a code paste

1. Save → reload the sheet  
2. **Make this spreadsheet simple**  
3. **What needs attention?** and work the list
