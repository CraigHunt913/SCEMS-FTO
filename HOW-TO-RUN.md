# How to run SCEMS (the short version)

This workbook is a **desk for Training**, not a filing cabinet you browse.

## Day to day

1. **SCEMS → Trainees — start here** — one row per person  
2. **SCEMS → Work my queue** — approve / return skills one at a time  
3. **SCEMS → What needs attention?** — when something feels off  
4. **SCEMS → Backup now** — about once a month  

That is the job. Everything else is machinery.

## Audit flags (tab 13) — how to clear them

Flags are **formulas**, not sticky notes. You cannot delete a FLAG cell and call it fixed.

| Color | Meaning | What you do |
| --- | --- | --- |
| **RED** | Condition is true; nobody owns it yet | Fix the data, **or** **SCEMS → Work audit flags** |
| **AMBER** | Same FLAG, but you Accepted / logged it | Still counts. Wait for data, or fix the source |
| blank | Clean | Nothing |

**Clear a flag for real** — fix what it is watching:

- **NO NARRATIVE** → FTO adds narrative on the eval  
- **SILENT RECORD** → evals / reflections start flowing again  
- **PHASE MISMATCH** → Current Phase on TRAINEES matches the latest eval  
- **ADV / REFLECT** → scores and requests converge  
- **FTO SCOPE** → roster or eval level corrected  

**Accept** (Work audit flags) does **not** erase the FLAG. It puts your name, a typed reason, and a ~90-day review-by on the record. The cell stays FLAG until the data changes. That is intentional.

Do **not** type over B5:G44, run retired bulk-clear tools, or expect Accept to blank the grid.

**Refresh the AUDIT layout** (banner + colors, formulas untouched):  
**Make this spreadsheet simple**, or More → Advanced → Refresh audit tab layout.

## If the tab bar looks like chaos

**SCEMS → Make this spreadsheet simple**

Hides Form Responses, ledgers, engines, and old role views. Deletes nothing.
Puts you on TRAINEES. Also refreshes the AUDIT banner.

## Who uses what

| Who | Where |
| --- | --- |
| You (Training) | This spreadsheet — decide and record |
| FTOs / trainees / MD | The **portal** (role screens) |
| Forms | The nine live Google Forms only — never a “Copy of …” |

## How to know everything is correct

1. Paste the branch `Code.gs`, save, reload the sheet  
2. **Make this spreadsheet simple**  
3. **What needs attention?** — work every WARN until gone (or only INFO left for owned flags)  
4. RED audit flags → **Work audit flags** (own) or fix source data (clear)  
5. **Backup now** when the desk is calm  

## When something breaks

1. **What needs attention?** — it names the exact next function  
2. **More → Repair forms & sheets** / **Recover skills & rebuild matrix** if it says so  
3. **More → Show every tab** only while repairing; then **Hide the clutter** again  

## What you should not do

- Do not delete Form Responses tabs on the live book (copy first, then clean the copy)  
- Do not submit to a form titled “Copy of …”  
- Do not paste code into the underscore-named twin spreadsheet  
- Do not use bulk-approve tools (retired on purpose)  
- Do not hand-edit the AUDIT FLAG grid (B5:G44)  

## After a code paste

1. Save → reload the sheet  
2. **Make this spreadsheet simple**  
3. **What needs attention?** and work the list  
4. **Work audit flags** for any RED cells you are living with
